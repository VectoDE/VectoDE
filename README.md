I'm Tim, a self-taught full-stack developer from Itzehoe in northern Germany. I founded [UplyTech](https://www.uplytech.de), a community and project for development, design, video and marketing, where I build websites, web apps, APIs and custom software and then host and maintain what I ship.

My first contact with computers and tech came in 2014, and my first Minecraft projects followed in 2016. In 2017 I started coding and taught myself from YouTube tutorials. That led to PlayGS, a Minecraft network with its own plugins, a shop and a TeamSpeak that I ran from 2017 to 2019. I played football for SSC Phönix Kisdorf until programming took over my evenings. Most of my own projects started as fixes for my own problems, like a music bot for my Discord server or a script that redeploys apps when I push. Most of my time right now goes into **Tellersonne**, my cooking app for iOS and Android, live at [tellersonne.app](https://tellersonne.app). Since October 2026 I've also been working on [VectolynCloud](https://github.com/VectoDE/VectolynCloud). In November and December I'm building the LineFM app in Flutter on the side.

Every project in one sentence:

- [Tellersonne](https://tellersonne.app): A calm cooking app for iOS, Android and tablets, with public recipe pages and a web admin panel. No ads, no third-party analytics.
- [VectoBeat](https://vectobeat.uplytech.de): Discord music bot with Lavalink v4 audio, playlists, fast queue handling and a dynamic equalizer, plus a Next.js control panel.
- [NodCord](https://github.com/VectoDE/NodCord): An Express API with a built-in Discord bot and dashboard. Your frontend runs inside the API or on its own.
- [ServerCommander](https://github.com/VectoDE/ServerCommander): A modular command-line tool for managing local and remote servers over SSH, FTP and more.
- [Self-Updater](https://github.com/VectoDE/Self-Updater): Watches a GitHub or GitLab repository and updates your app under PM2 or Docker when something new lands.
- [Linux Server Setup](https://github.com/VectoDE/Linux-Server-Setup-Script): Turns a fresh Debian, Ubuntu, CentOS or RHEL machine into a production web server with Nginx, PHP, MySQL, Node.js, Fail2Ban and SSL.
- [Portfolio](https://github.com/VectoDE/Portfolio): Portfolio site with its own dashboard and API for managing projects and content.
- [VectolynCloud](https://github.com/VectoDE/VectolynCloud): Kit for running your own Minecraft network. Its own cloud manages proxies, servers and plugins, and Java and Bedrock players play together.
- [RelationNotes](https://github.com/VectoDE/Notebook-LM-Klon): Research notebook in the style of NotebookLM: hybrid search over your own sources, running as one Cloudflare Worker with D1 and R2.
- [LifeVerse](https://github.com/VectoDE/LifeVerse): Concept for an open-world life simulator with a dynamic story, AI-driven characters and multiplayer.
