Ich bin Tim, Full-Stack-Entwickler aus Itzehoe und habe mir das Programmieren selbst beigebracht. Ich führe [UplyTech](https://www.uplytech.de), einen IT-Dienstleister, der Websites, Web-Apps, APIs und individuelle Software für Kunden baut und das Ergebnis danach auch hostet und pflegt.

2014 hatte ich den ersten Kontakt mit Computern und Technik, 2016 habe ich angefangen, mir das Programmieren mit YouTube-Tutorials beizubringen. Daraus wurde 2017 [PlayGS](https://www.playgs.de), ein Minecraft-Netzwerk mit eigenen Plugins, Shop und TeamSpeak, das ich bis heute betreibe. Bevor das meine Abende gefüllt hat, habe ich beim SSC Phönix Kisdorf Fußball gespielt. Die meisten meiner eigenen Projekte sind aus eigenen Problemen entstanden, etwa ein Musikbot für meinen Discord-Server oder ein Skript, das Apps nach jedem Push neu ausrollt. Die meiste Zeit steckt gerade in **Tellersonne**, meiner Koch-App für iOS und Android, live auf [tellersonne.app](https://tellersonne.app).

Alle Projekte in einem Satz:

- [Tellersonne](https://tellersonne.app): Eine ruhige Koch-App für iOS, Android und Tablets, mit öffentlichen Rezeptseiten und Web-Adminbereich. Ohne Werbung, ohne Tracking.
- [VectoBeat](https://vectobeat.uplytech.de): Discord-Musikbot mit Lavalink-v4-Audio, Playlists, schneller Warteschlange und dynamischem Equalizer, dazu ein Next.js-Control-Panel.
- [NodCord](https://github.com/VectoDE/NodCord): Eine Express-API mit eingebautem Discord-Bot und Dashboard. Dein Frontend läuft in der API oder eigenständig.
- [ServerCommander](https://github.com/VectoDE/ServerCommander): Ein modulares Kommandozeilen-Tool, mit dem du lokale und entfernte Server per SSH, FTP und mehr verwaltest.
- [Self-Updater](https://github.com/VectoDE/Self-Updater): Beobachtet ein GitHub- oder GitLab-Repository und aktualisiert deine App unter PM2 oder Docker, sobald etwas Neues kommt.
- [Linux Server Setup](https://github.com/VectoDE/Linux-Server-Setup-Script): Macht aus einer frischen Debian-, Ubuntu-, CentOS- oder RHEL-Maschine einen Produktions-Webserver mit Nginx, PHP, MySQL, Node.js, Fail2Ban und SSL.
- [Portfolio](https://github.com/VectoDE/Portfolio): Portfolio-Website mit eigenem Dashboard und eigener API für Projekte und Inhalte.
- [VectolynCloud](https://github.com/VectoDE/VectolynCloud): Baukasten für ein eigenes Minecraft-Netzwerk. Die eigene Cloud verwaltet Proxys, Server und Plugins, Java- und Bedrock-Spieler spielen zusammen.
- [RelationNotes](https://github.com/VectoDE/Notebook-LM-Klon): Recherche-Notizbuch nach dem Vorbild von NotebookLM: hybride Suche über eigene Quellen, läuft als ein Cloudflare Worker mit D1 und R2.
- [LifeVerse](https://github.com/VectoDE/LifeVerse): Konzept für eine Open-World-Lebenssimulation mit dynamischer Story, KI-gesteuerten Figuren und Mehrspieler-Modus.
